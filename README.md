# Tarantula Studio

Linux-приложение с графическим интерфейсом для настройки геймпадов
**GameSir T4 Nova Pro (Super Nova)** и **GameSir Tarantula (Pro)** без Windows,
проприетарных DLL и виртуальной машины. Приложение говорит с контроллером
напрямую через `/dev/hidraw`.

> **Поддерживаются только два устройства: GameSir T4 Nova Pro (Super Nova) и
> GameSir Tarantula (Pro).** Другие модели GameSir не поддерживаются и могут
> вести себя непредсказуемо — не записывайте конфигурацию на них.

**Главная особенность:** в режиме мыши (Mouse / HID) DPI можно задавать в
диапазоне **0–255**, а не 0–100, как в официальном GameSir Connect. Поле
прошивки однобайтовое, поэтому верхняя граница — 255. Значения выше 100
помечены как экспериментальные: после записи приложение всегда перечитывает
конфигурацию и показывает предупреждение, если прошивка ограничила значение.

> Статус: альфа. Протокол и интерфейс проверены автотестами, но полная проверка
> на живом Tarantula Pro ещё не выполнялась. Перед записью всегда создаётся
> резервная копия.

## Возможности

- **Мышь и DPI** — режим мыши, DPI X/Y 0–255, инверсия, угол перекрытия,
  измерение реальных REL_X/REL_Y для проверки, что DPI выше 100 действует.
- **Стики** — режимы «Нативный», «Мышь», «Клавиши по зонам (wheel)», «Клон»,
  мёртвые зоны, анти-мёртвые зоны, кривая из трёх точек, круглая зона,
  соотношение осей, клавиши внутренних и внешних зон wheel-режима.
- **Курки** — быстрый курок (adaptive/fixed), пороги, кривая и мёртвые зоны LT/RT.
- **Кнопки** — переназначение на кнопки контроллера, клавиатуру, мышь и
  медиа-клавиши; турбо и режим переключателя; сброс к заводскому значению.
- **Макросы** — до 12 шагов для L4, R4, T1–T3, C1–C4; удержание и цикл.
- **Гироскоп** — выход на стик/клавиши/мышь, ось, кнопка и способ активации,
  чувствительность, инверсия, кривая, клавиши направлений.
- **Подсветка** — режимы, яркость, скорость, цвета Panel/Home/ABXY/BAYX в HSV.
- **Вибрация** — сила моторов, виброотклик курков, тест моторов.
- **D-Pad и раскладка** — 4/8 направлений, swap, ABXY/BAYX, auto on/off,
  fast trigger, кнопка переключения макросов.
- **Профили и копии** — локальные профили, автоматические резервные копии перед
  каждой записью, импорт/экспорт JSON.
- **Диагностика** — поиск hidraw, проверка прав, установка udev-правила через
  `pkexec`, список узлов мыши, журнал.
- **Демо-режим** — полноценная работа с локальной копией конфигурации без
  контроллера.

## Требования

- Linux с `/dev/hidraw` (ядро с HIDRAW), X11 или Wayland.
- Python 3.10+.
- PySide6 6.5+.

На Arch Linux:

```bash
sudo pacman -S python-pyside6
```

На Debian/Ubuntu:

```bash
sudo apt install python3-pyside6.qtwidgets
```

Других зависимостей нет: hidraw, ввод и мышь читаются через стандартную
библиотеку Python.

## Запуск

Из каталога проекта:

```bash
./tarantula-studio
# или
python3 -m tarantula_studio
```

Демо-режим (без контроллера):

```bash
./tarantula-studio --demo
```

Установка ярлыка в меню и лаунчера для текущего пользователя:

```bash
./tools/install-user.sh
```

Скрипт кладёт `tarantula-studio` в `~/.local/bin`, `.desktop` — в
`~/.local/share/applications`, иконку — в `~/.local/share/icons`. Убедитесь, что
`~/.local/bin` есть в `PATH`.

## Права доступа к контроллеру

Без udev-правила `/dev/hidraw*` обычно доступен только root. Откройте страницу
**«Диагностика»** и нажмите **«Установить правило»** (потребуется pkexec), либо
установите вручную:

```bash
sudo install -m 644 udev/70-gamesir-tarantula.rules /etc/udev/rules.d/
sudo udevadm control --reload-rules
sudo udevadm trigger
```

После установки отключите и снова подключите геймпад. Правило:

```udev
SUBSYSTEM=="hidraw", ATTRS{idVendor}=="3537", TAG+="uaccess"
SUBSYSTEM=="input", ATTRS{idVendor}=="3537", TAG+="uaccess"
```

## Режим контроллера

Приложение ищет поддерживаемые идентификаторы:

| PID    | Устройство                                            |
|--------|-------------------------------------------------------|
| `103e` | T4 Nova Pro (Super Nova) донгл / Tarantula, 2.4 ГГц   |
| `1050` | Tarantula Pro, USB-C провод                           |
| `100e` | T4 Nova Pro (Super Nova) / Tarantula, провод          |

Нужен режим **PC/XInput**. На некоторых прошивках он включается удержанием
**Home + X** около 2 секунд. Если контроллер виден как Xbox-устройство с другим
PID, переключите режим и переподключите кабель.

## DPI выше 100: как проверить

1. Подключите контроллер и нажмите **«Прочитать»**.
2. Откройте **«Мышь и DPI»**, выберите стик и режим **«Мышь (HID)»**.
3. Включите **«Начать измерение»** и сделайте стиком медленный полный круг.
4. Запишите DPI 50, 100, 150 и 255, повторяя одинаковое движение.
5. Смотрите на счётчики `dx/dy` и на строку **«Обратное чтение»**.
   - Значения растут пропорционально, обратное чтение совпадает — DPI работает.
   - После 100 счётчики не растут или чтение возвращает 100 — прошивка
     ограничивает диапазон. Тогда нужен программный слой (виртуальная мышь
     через uinput), который пока не реализован.

То же самое из CLI:

```bash
python3 -m tarantula_studio dpi --sweep 50,100,150,255 --measure 3 --side right --backup
```

## CLI

```bash
python3 -m tarantula_studio --help-cli
```

Основные команды:

| Команда | Назначение |
|---------|------------|
| `doctor` | Проверить устройство, права, udev и узлы мыши |
| `read [--json] [--save]` | Считать конфигурацию |
| `dpi 150` | Записать DPI и перечитать |
| `dpi --sweep 50,100,150,255 --measure 3` | Серия замеров движения |
| `apply config.json` | Применить JSON-конфигурацию |
| `restore backup.json` | Восстановить резервную копию |
| `backup` | Считать и сохранить копию |
| `mouse-scan`, `mouse-test` | Проверить интерфейс мыши |
| `udev-rule` | Напечатать udev-правило |
| `gui [--demo]` | Запустить графический интерфейс |

Данные приложения хранятся в `~/.config/tarantula-studio/`
(переопределяется переменной `TARANTULA_STUDIO_CONFIG`): `config.json`,
`profiles/`, `backups/`.

## Безопасность

- Перед каждой записью автоматически создаётся полная резервная копия.
- Записываются только изменённые разделы; после записи выполняется обратное
  чтение и сравнение.
- Если прошивка изменила значение, приложение показывает предупреждение, а не
  молча продолжает.
- Команды обновления прошивки, сопряжения и калибровки намеренно не
  реализованы.
- Откат: загрузите резервную копию на странице **«Профили и копии»** и нажмите
  **«Применить»**.
